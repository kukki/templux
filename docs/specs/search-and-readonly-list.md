# T11 统一搜索与只读列表使用合同

2026-10-15，依据#12/#1、统一搜索/网页元素规范、ADR0012/0013与T10独立示例合同。通用组件在apps/web/app/components/elements，纯语义与异步协调在shared/search及shared/latest-query；不依赖examples。示例单向使用，完整筛选/分页排序/编辑后续实现。

## 采用时必须提供

SearchList<Row>需要fields（唯一key、可见label、显式read访问器）、matches匹配函数、load数据读取实现、columns列显示与rowKey稳定ID、caption、hint及运行时settings。没有默认全字段读取/匹配或示例fallback。只读显示结果，组件不提供编辑/保存接口；列render由项目控制，不应用它偷偷授编辑资格。

默认matches可显式选择containsFields，整段trim/toLowerCase，指定字段任一包含，空词返回该读取范围内全部行，不按空格拆词、不序列化整行。未指定的其它字段不会被隐式搜索；read只接受项目明确的字符串/数字字段，复杂值要项目显式转换。项目可提供其它匹配实现并注明差别，不能把默认语义声称仍不变。

load({term,signal})返回Promise<ListResult<Row>>：success+rows、error或forbidden。已trim/lower的term对应本次条件；AbortSignal供取消，取消不代表服务端停止或写操作回滚。结果到达后matches在显式字段上筛选一次；本票无服务端分页/总数，适用于完整获授权读取范围或已有过滤结果，不把部分页面当全体。大数据/后台检索项目实现自己的服务端匹配、范围、容量与分页接口，服务端搜索必须显式允许字段且参数化；浏览器过滤不是授权。

403业务无资格映射forbidden、网络/读取错误映射error，不误退出；明确401及已知会话原因由现有SessionGuard/session-client失效处理立即回登录，不能映射空结果或延迟强制退出。组件本身不持有身份、不调用固定业务API、不替代后端最新权限检查。

## 输入和异步语义

elements.search新增可省分支：delayMs400（整数1–1000）、showButton=false。旧schema1配置未写search补默认，显式null/空对象/部分字段/错误类型拒绝；完整覆盖并重启后生效，不改现用config/presentation。真实项目可传该配置覆盖，采用搜索的业务fields/matcher/source仍必填。

输入草稿即时显示，停顿配置毫秒后应用/触发读取，不承诺结果在1秒内完成。默认无独立搜索按钮，可显式显示；Enter取消等待并立即应用。相同已应用词不重复读取，错误重试可明确重读。清空原生输入或“清空搜索”立即应用空词；不自动清掉搜索来掩盖空结果或错误。

中文composition期间保留草稿、取消等待、不应用中间文本；compositionend后以最终input值重新计时。转换中的Enter/isComposing/229及结束后100ms保护期不作为额外提交，避免浏览器先结束组合再发Enter造成误查；正常后续Enter立即应用。保护期仅影响即时提交，最终文字仍按停顿触发。后台/繁忙浏览器可能延迟定时器，前台验收记录触发延迟，不把网络时间混入。

每次新输入意图（含debounce等待及IME开始/提交）立即使旧版本失效并取消旧请求，显示独立等待输入状态，不冒充已经读取；即使规范化后与上次词相同，被取消的读取也会在提交后重新执行。每次读取递增版本并取消旧请求，忽略旧成功/错误/无资格；即使调用者不理AbortSignal，旧结果也不能覆盖新条件。输入新应用条件时立即invalidate旧任务，卸载/重置也取消并忽略。真实HTTP延迟测试与浏览器情景分别覆盖。源函数/字段/匹配实现应稳定（模块常量或useCallback/useMemo），否则引用变化是新的读取依据；不在每次render无意创建新源导致反复加载。

## 显示与访问性

搜索字段名称与提示在同一边框内，原生label和可访问名称持续存在；宽度随容器伸展，窄屏换行，不裁字段名。只读表保留所有列，thead scope/标题、稳定key；滚动容器可聚焦并用键盘横移，触屏仅容器横滚、不让页面横溢出。

waiting、loading、error、forbidden及success-empty分别有标题/说明；空结果跨全部列且保留表头、搜索、可选上层筛选，不自动重置；加载和无权限不得伪装零行。错误有明确重试，未知错误文本不原样渲染。其它项目文案可替换集中config/elements-copy.json或组件采用处，不建设消息中心。

## 示例与测试边界

/examples保留真实认证与SessionGuard，新增独立search-data及search-demo：五列三条合成记录，只指定名称/编号搜索，其它展示列不参与。正常/慢速/较早查询延迟/失败/无资格为明确标识的样例读取情景，不改变真正身份；只用浏览器内存Promise，未加产品API/SQL。显示搜索按钮为可选演示，重置恢复项目默认/初始数据与搜索。

tests/search.test.mjs除语义和配置兼容外，在隔离测试进程启动实际HTTP延迟来源，验证旧慢/新快、忽略abort、清空/销毁及不同结果；测试服务不打包进生产。正常examples HTTP和浏览器通过实际正式认证/0008 SQL；从可观察DOM/结果/触发时机验收，不添加生产观测后门。

真实HTTP适配须先判断状态：已知会话401读取安全reason后调用现有session-client.endSession立即失效；业务403返回forbidden，其它非成功及网络/解码故障返回error。成功解码需项目验证Row形状/授权范围后返回success。不要把response.json()的任意对象当数组、把失败默认返回空数组或自己实现等待倒计时的登录跳转。该适配由新项目提供，本模板未新增假业务读取接口。

新增search分支需要本票读取代码；旧版解析器仍可能拒绝未知分支，不声称旧镜像能识别新增配置。先部署匹配读取版本，再用已有配置覆盖并重启；原文件不增加分支即可沿本票默认兼容。
