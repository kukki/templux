# T10 控件示例实现与扩展合同

2026-10-15，依据Gitea #11/#1、控件示例/网页元素规范及ADR0012/0013、0007/0008/0021。本票实现独立入口与最小内存体验，完整控件行为在T11–T20逐项交付。

## 入口、开关与权限

登录后的/account在有application:read时展示“控件示例”，路径/examples。通用shared/features读取DEPLOYMENT_ENV及COMPONENT_EXAMPLES_ENABLED，后者auto/true/false：未设置与auto随DEV/UAT启用、PROD关闭，true/false显式覆盖。开关或部署环境的空值、其它拼写拒绝；Compose对开关/部署环境只在未设置时提供auto/PROD，隔离测试环境默认DEV，显式空不被吞掉。Web启动、管理start/config-check使用同一校验；修改部署配置后重建/重启相应容器环境，不需改示例代码。开关不修改账号角色或Agent登录策略，生产Agent仍默认不可登录。

关闭时/examples返回404，不做认证数据请求，不输出合成数据；账号页不显示入口。启用时SSR先使用已有真实/api/protected、持久Cookie/no-store与后端application:read校验：匿名401回登录；Pending/零角色/缺权限403回account；禁用/撤销/版本改变按会话原因回登录。管理员、普通用户及获正常角色且符合环境策略的Agent可以进入，没有额外管理授权。失败不可用与明确401/403区分、保留原路由重试；SessionGuard沿心跳/失效/活动合同，不通过示例绕过生命周期。

没有示例业务API/数据库表；/api/protected是既有通用授权准入，不提供示例数据。任何地址参数、内存样例或开关都不授认证权限。页面仅展示样例，管理账号与审计始终使用真实后端。

## 单向依赖和物理移除

- app/examples包含page.tsx、lab.tsx、data.ts、examples.css；独立文案config/examples-copy.json。页面向通用shell/profile/SessionGuard/presentation依赖，通用业务代码不import示例目录或独立文案。
- Account只依赖通用features与通用导航文案链接；shared/features是项目公共开关配置，不装载样例。示例全部源码可独立删除。
- 新项目关闭入口：设置COMPONENT_EXAMPLES_ENABLED=false并重新创建Web容器环境。
- 完全移除：先关闭，再删除apps/web/app/examples与config/examples-copy.json；重建Web。通用features及通用入口标签可保留（禁用后无链接），可按项目自行移除公共开关/标签，但不需要修改认证、管理、审计或数据库。删除代码不等同仅运行关闭配置，验收分别验证。
- 移除副本不删除既有模板测试/迁移或用户数据；后续采用共享控件时控件代码应位于通用目录，示例单向import，不将正式控件实现放在示例目录供业务反向引用。

## 合成数据与操作

独立data.ts提供三条sample-a/b/c与“示例条目A/B/C”，每次freshSamples产生新对象，无来源业务/人员信息。客户端useState初始化，改第一条名称、标准/紧凑示例布局仅改变当前页面内存。按钮“应用到示例”明确区别正式保存；名称必填、最多80字符，空白不应用。重置恢复全体数据、名称和密度，刷新/重新进入恢复默认。没有localStorage/sessionStorage、Cookie样例存储、URL持久化、上传或示例网络写操作。

身份心跳/活动等既有认证请求正常发生，不把它们当样例写入。真实权限失效可强制返回登录；示例不增加未保存拦截来阻止它。

样例默认成功同步显示；本票不模拟整套业务加载/故障流程。后续异步控件演示须用此目录内的独立浏览器适配器和人工可控成功/失败/延迟，明确标识模拟状态，不能让模拟错误影响真实认证或创建示例服务API。

## 元素演示合同

项目通用默认来自presentation.elements，经既有完整运行时校验；当前页只读显示分页pageSize/pageSizes、通知durationMs及桌面/窄屏可见数，并使用项目theme/header/footer。默认分页10且5/10/15/20/25/50可选、普通通知15秒及3/1；这是默认值展示，不声称本票已实现完整分页/通知控件。标准/紧凑只作为此示例布局变体，不改全项目主题或默认值。

后续每个演示应满足下面三个层次，具体控件导出接口由对应票记录，本票不预设内部组件实现：

| 层次 | 使用要求 |
| --- | --- |
| 项目默认 | 读取已校验通用默认，不在示例或业务硬编码另一套默认；新增字段先扩展配置合同/校验及独立验收 |
| 必填适配 | 项目显式提供字段/标签、稳定ID、数据与实际操作实现；未提供显示未接入或明确拒绝，不能用全部字段或假成功替代 |
| 可选变体 | 明确演示启用条件、默认行为与替代行为；仅在样例内使用独立数据，不偷偷改变真实管理权限 |

| 后续元素 | 需由项目/演示提供 | 可选/默认方向 |
| --- | --- | --- |
| 导航 | 项目菜单/合法目标/图标与文字 | 配置方向、展开/收起及窄屏抽屉 |
| 搜索/多选 | 搜索字段与匹配实现、选项稳定ID与列表筛选实现 | 显式搜索字段；列表与表单分开，不擅用全部字段 |
| 分页/排序/空结果 | 数据总数、合法页、基础次序/允许排序字段、正确状态 | 默认10/数量集合，控件可隐藏部分；错误不冒充空结果 |
| 表单/表格/弹窗 | 字段标签、校验、行ID和保存/取消实现 | 只读默认，编辑显式启用；按对应行为合同处理未保存/保存中 |
| 通知/维护 | 内容/严重程度、维护生命周期 | 普通15秒/容量配置，维护不混普通队列 |
| 图片/复制/浮层面板 | 有效源/列表、完整复制值及名称、触发/内容 | 图库/缩放/空值策略/面板变体按需启用 |

公共文案集中替换，业务字段/数据属于项目；本票名称与密度是独立体验，不作为完整表单/表格/导航控件验收替代。使用键盘原生input/select/button和可见焦点，手机单列、不让整页横向溢出。
