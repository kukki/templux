# Templux 首版通用模板项目规格

## Problem Statement

后续软件项目需要重复建设登录认证、轻量用户管理、日志、部署和常用界面元素。Supplieroom、Skoope、Catchouse 已积累相关实现，但行为、风格、配置和运维方式分散，直接复制整套项目容易夹带业务逻辑，也难以让既有项目持续获得公共改进。

项目创建者需要一个可独立启动、可按项目配置呈现与交互、可容器化管理的通用模板项目。网页元素应有明确规范，供新项目按需采用；新项目产生的通用改进应经过审查反哺模板，再通过可审查升级提案惠及其它项目。

## Solution

交付 Templux 首版：以三个来源项目为实现参考，提供独立前后端、真实认证与账号管理、结构化运行日志和审计、Docker 部署与管理 CLI、项目级呈现配置、规范化网页元素和可移除控件示例。

新项目复制模板源码或源码包，通过容器内初始化命令设置名称、品牌和配置；选择所需网页元素，并实现自己的业务字段、流程与业务范围。稳定通用能力以带版本和校验信息的共享包文件分发。各项目受控自动化发现模板更新后生成补丁、变化清单和检查报告，由维护者确认应用，不自动合并或部署。

首版完成的标准是：模板可独立运行；新项目可完成初始化与项目变体配置；人员和获授权 Agent 可通过真实登录流程访问；权限变化可可靠使旧会话失效；管理、备份、恢复和升级提案可通过容器入口操作；已确认网页元素通过行为验收。

## User Stories

2. As a 项目创建者, I want a 汇总三个来源项目共通能力的起点, so that 我不必重复实现基础设施。

6. As a 项目维护者, I want a 经审查反哺通用改进的流程, so that 其它新项目和既有项目可以受益。
7. As a 项目维护者, I want a 锁定的模板共享包版本, so that 构建不会无意跟随最新版本变化。
8. As a 项目维护者, I want a 含版本和校验信息的共享包文件, so that 我可以核对使用的发布产物。

## Implementation Decisions

- **交付模块与所有权**：建设认证与会话、轻量账号及授权、审计与运行日志、项目配置、网页元素、控件示例、容器管理、备份恢复、发布清单与升级提案能力。稳定共通能力属于版本化共享包；业务、项目配置和应用骨架属于新项目。具体导出接口和扩展合同在实施设计中明确，不能通过升级覆盖业务或绕过认证。
- **技术方向**：前后端使用 TypeScript；Next.js 前端与 Fastify/Node.js 后端独立构建发布，通过明确 API 交互，可同仓库统一启动。静态类型不代替运行时输入校验。具体版本在实施时选定并锁定。
- **数据与迁移**：默认 PostgreSQL，Compose 自带数据库且支持外部连接；使用 pg 参数化 SQL 和版本化 SQL 迁移，不引入 ORM。应用启动前由管理容器迁移并校验，失败中止部署，Web 进程不迁移。需要持久化账号、登录关联、角色授予、会话及撤销、授权版本、登录失败记录和审计；具体表结构由实施设计提出，不固化业务范围字段。
- **配置分离**：项目名称、品牌、设计变量、布局、文案及元素默认值通过独立受版本管理配置载入；环境与密钥由 .env 提供，运行数据独立保存。已有呈现配置值修改后重启相关服务即可生效，不需重建镜像；新增代码或未打包资产仍需构建。
- **项目变体**：面向项目维护者配置，不提供终端用户主题或导航方向切换。默认浅色背景、蓝色强调，响应式；支持深黑、深褐、浅蓝、深黄等项目配色方向，具体设计变量在实现时统一定义。变体范围不限于主题与导航。
- **语言与时间**：默认简体中文，通用文案集中管理，新项目可替换语言与业务文案；管理审计时间显式使用 Asia/Hong_Kong，默认显示到秒，项目可改，不截断底层时间精度，不统一业务日期或存储类型。
- **部署与准入**：每套部署服务一个组织及其合作方；面向内部员工和受邀合作方，不开放公众注册。飞书长期凭据使用 App ID、App Secret，组织校验使用 tenant_key，并通过环境配置提供；运行时令牌不能替代长期凭据。认证协议及用户身份验证合同须按实施时官方文档核对。
- **账号与角色**：默认预定义管理员、普通用户；可多角色，权限取并集，零角色无业务访问。Pending 是账号状态。首次飞书登录 Pending，通过 CLI 授权，可建立首位管理员，不自动授权首个登录者。新项目可扩展角色、互斥约束和授权方式。
- **管理员保护**：已存在有效管理员后，常规网页及 CLI 拒绝停用或降权最后一个有效管理员；首次零管理员初始化允许建立管理员。并发操作须共同维护这一不变量，具体恢复方案在实施设计中说明。
- **登录关联与改密**：人员可只用飞书、只用授权密码或验证后关联两者，共享账号状态、角色和审计。仅管理员通过网页或 CLI 发起关联及启用密码；不按姓名或邮箱自动合并。首版人员仅管理员重置密码，系统随机生成；交付与绑定验证方式须在实现前明确并记录，不能声称已由访谈选定。
- **Agent 身份**：独立账号关联责任人，默认无权限，显式授予正常角色，经过同一后端授权检查；DEV/UAT 可用，PROD 默认关闭，可显式启用。CLI 创建和重置，通过正常密码登录页认证，不新增认证后门。初始随机密码仅写指定受限文件，不打印普通输出、不静默覆盖已有文件。长期授权直到撤销，与会话期限独立。
- **持久会话**：PostgreSQL 保存会话及撤销信息，正常重启保持有效会话。同账号允许多设备独立会话，分别超时。普通退出撤销当前会话，另提供全部退出；同浏览器共享 Cookie 的标签页共用会话，不建设设备列表。
- **会话期限与心跳**：人员及 Agent 最长会话均默认12小时，闲置默认10分钟，人员闲置可由 .env 覆盖，Agent 使用独立配置覆盖期限与闲置。可见且在线页面默认30秒检查，配置可覆盖；恢复可见或网络恢复立即检查。心跳不算真实用户活动，不延长闲置，不保证后台浏览器精确计时。
- **即时授权核验**：每次受保护请求核对数据库最新会话撤销、账号状态与授权版本。禁用、权限调整、管理员重置密码提升版本并使旧会话失效；同人员的飞书旧会话也失效。变更提交后新发起请求不按旧权限放行，不承诺撤销已执行请求效果。新项目业务范围变化通过统一失效能力接入，不内置范围引擎。
- **失效反馈**：明确会话失效后立即清除前端登录状态，返回登录页持续显示原因，不等待倒计时或确认，未保存提醒不阻挡。普通网络故障和会话仍有效的业务403不能误判为会话失效。
- **密码失败保护**：按来源 IP 与规范化用户名组合计数；首次失败起15分钟窗口内累计5次后，从触发时起固定限制15分钟；受限期间不继续累计，成功登录清理该组合。PostgreSQL 持久化与事务控制，重启保留未过期限制，同库实例共享。配置合同、过期清理和可信代理 IP 获取属于实施安全设计，不直接相信调用方伪造地址。
- **日志与审计**：运行日志结构化，通过 Docker/CLI 查看，预留外部平台接入；管理员网页只查询关键操作审计，支持搜索、筛选、分页，无首版导出。审计覆盖认证、账号、授权撤销、Agent 和维护管理；CLI 记录来源、目标、结果，操作者可信度依赖宿主身份机制。审计默认90天自动清理可配置；运行日志按容量轮转限制总量，以约14天为目标，容量先满可更早淘汰。
- **审计故障语义**：账号、角色、登录关联等关键数据库管理变更必须可靠保存审计，否则不提交并明确失败。账号及会话正常而密码成功登录审计单独失败时允许登录并记录运行错误，不假装审计已保存，数据库整体不可用时不能绕过认证。其它事件失败策略在实施设计中逐类说明，不扩大这两个已定例外。
- **CLI 入口与授权**：Ubuntu UAT/生产与 macOS 可选开发 Shell；Windows/WSL2 已移出支持与验收范围，Ubuntu 版本/架构待环境核验，见 [平台范围](deployment-platforms.md)；宿主仅需 Docker、Compose、基础 Shell。宿主包装只转交容器调用、参数和退出码；菜单、解析、校验和实际操作均容器执行。管理可在 Web 未启动时运行。获准执行管理容器并访问部署凭据的宿主操作者无需再登录应用管理员；浏览器 Agent 账号不获得宿主权限。
- **CLI 交互合同**：无参数且有终端进入菜单；完整参数直接执行，支持显式非交互。无终端或非交互缺必填项立即非零退出，不等待输入。管理变更人工展示摘要并确认，自动化须有显式确认参数，只读无需确认。默认文本，可选 JSON；JSON stdout 仅结构化结果，日志诊断 stderr，凭据不在普通输出中。
- **备份与迁移**：已有数据库且有待迁移项时默认先备份，失败中止；空库初始化或无迁移跳过。可显式提供外部备份路径、快照 ID 或记录编号并写操作记录，操作者负责可恢复性，模板不宣称已验证。仅备份数据库，代码配置通过版本库恢复，.env及必要密钥单独准备；不自动恢复失败部署。
- **备份保留与恢复**：默认最近5份成功的迁移前自动备份可配置，只有新成功后清理超额，不清理手动或外部备份。支持独立目标与原库恢复，每次明确模式和目标，无默认；原库先停写并确认，外部数据库不假设建库权限，不自动切换生产连接。成功恢复后开放访问前使全部恢复出的旧会话失效。
- **页头页脚**：默认随页面滚动；页头项目名称、可选 Logo、当前账号、退出与导航；页脚项目版本和可配置版权，可隐藏替换。固定或吸附可作为项目变体，不固化来源品牌。
- **导航**：桌面默认纵向，项目可选横向；纵向支持文字隐藏仅图标。项目设默认展开状态及是否允许用户收起，允许时按当前浏览器、项目、账号保存，不跨设备；禁用切换时以项目配置为准。窄屏菜单按钮打开文字侧边抽屉，选择页面后关闭，不保留桌面图标栏占宽。
- **统一搜索**：采用时新项目必须提供搜索字段及对应搜索实现；一个入口，内嵌字段名称和提示，长度自适应。停止输入后1秒内应用条件并触发查询，不承诺查询完成时间。可选按钮默认隐藏。默认整段输入去首尾空白、忽略大小写、指定字段任一包含匹配，不按空格拆词，项目可显式扩展。
- **列表多选筛选**：选中立即反馈，停止勾选1秒后应用，提前关闭立即应用，无确认按钮；不强加给表单或显示字段控件。复选框、文字和高亮行空白均可点击，单次只切换一次。全选表示不额外限制，全不选无结果；下拉内搜索后的全选只作用当前可见结果，保留隐藏项，明确标示“全选当前结果”。
- **分页**：默认完整组合，包括总数、每页数量、当前/总页数、首页/上页/页码组/下页/末页、跳页，可按项目隐藏可选部分。默认10条，选项5、10、15、20、25、50，项目覆盖时默认须属于集合。大小改变回第一页，边界禁用，默认下拉合法页码跳转。窄屏显示上页、当前/总页、下页，其余可展开访问。
- **排序与列表状态**：排序按需启用，不强制每列；单字段，改变回第一页，项目提供可排序字段、基础次序和数据实现。表格默认排序下拉与表头并存同步，表头新列升序、同列降序、再取消回基础次序，项目可改。排序、页码、每页数量默认写地址参数，刷新恢复，替换当前历史条目，不每次新增。搜索词和业务筛选保存策略未由此确定；地址参数不授予访问权限。
- **无匹配结果**：正常成功查询无匹配时保留搜索筛选及分页数量入口，不自动清空；默认简短标题加一行调整条件说明，表格保留表头、表体跨列空提示，文案和形式可配置。加载错误、权限不足、数据源未接入不能混为空结果，项目正确提供状态。
- **表单与编辑**：普通字段名称持续在上方，提示错误就近；首次失焦校验，提交全校验，错误字段修改及时复查，服务端最终校验。实际未保存编辑离开应用页面或关闭编辑窗先确认，搜索筛选不触发，不自动保存；浏览器离开使用支持的原生提示，不保证所有场景出现。强制失效退出不受阻。
- **表格与内联行**：默认只读无编辑入口；显式启用后按行编辑、保存/取消，保存才提交，失败保留输入。窄屏保留全部列，仅表格容器横向滚动，不使整页溢出；可配置卡片或优先列加详情，不固化字段或列权限。
- **编辑弹窗**：非保存中按钮、取消、Escape 可关闭，遮罩不关闭；未保存确认放弃。保存中显示忙碌，禁止关闭、取消、Escape及重复提交；成功或错误解除。超时解除等待并说明结果未确认，不自动重试写操作，超时不表示后端已取消；会话强制退出仍优先。
- **普通通知**：顶部默认15秒，倒计时进度和手动关闭；鼠标悬停或键盘焦点暂停，离开按剩余时间继续。触屏不加专门暂停按钮或正文点击暂停。桌面最多3条、窄屏1条可配置，超额FIFO等待，每条显示时才计时。
- **通知去重与溢出**：可选显式去重键与同严重程度的活动项合并并计数，无键不按文字去重；不合并已结束项。合并保留剩余时间、暂停及队列位置，不重新计时。等待队列满时丢最早等待项保留最新，累计省略数另作摘要，不移除正在显示项。容量、同键内容变化等细节由实现补齐，不建设消息中心。
- **维护**：维护通知独立于普通队列，持续倒计时，不可关闭收起，刷新导航不清除，管理员取消或结束才移除；到点继续提醒，不自动停止服务或改变业务写入权限。实际停服由运维执行，保留仍运行的访问入口提供统一风格维护页；具体入口部署及停写恢复机制由实施设计明确。
- **图片**：默认等比适配视口，按钮、遮罩或 Escape 关闭，点图片本身不关闭；关闭恢复打开控件焦点，前提仍存在可聚焦。缩放拖动为可选。图库项目传列表启用后显示上/下一张与位置，边界禁用不循环，换图重置缩放平移。备选源为同一图片依次尝试，全部失败占位，无有效源禁用预览，不默认重试按钮；不混同图库切换。
- **浮层与独立面板**：同时提供依附控件浮层及非模态独立面板。独立面板可配置桌面标题拖动和调整大小，受视口和最小尺寸限制，关闭可访问；窄屏底部非模态、内容滚动，无阻挡遮罩、无自由拖动调整，页面其它区域仍可用。同时一个独立面板，替换须遵循未保存及保存中关闭规则。
- **复制**：按需提供完整目标值和可识别名称，空值不提供可用复制按钮，隐藏或禁用可配置；不复制视觉截断内容，不强加业务 trim。成功原按钮确认默认约1.5秒后恢复可配置；失败本地提示及辅助反馈，允许再试，不显示假成功，不默认页面级错误。
- **控件示例**：模板独立运行提供登录、账号管理和控件示例，不建完整样例业务。示例独立可移除，开发验收默认开启、生产默认关闭，可配置。样例数据独立，浏览器内存模拟，刷新重置，无示例业务 API 或表；认证、账号和审计仍真实后端。只有已批准有角色人员及获授权 Agent 可访问，示例不授予管理权。
- **创建与共享发布**：首版复制源码再容器初始化，不另做目录脚手架生成器；共享包以有版本及校验信息的发布文件分发，不要求独立私有包仓库。共享统一版本及受检查组合清单，前后端仍独立发布、校验兼容，应用业务版本独立，不跟随 latest。产物存放与获取授权在实现设计中记录。
- **升级与反哺**：新项目通用改进经审查纳入，业务数据不反向同步；项目受控自动化默认每日可配置检查，也可手动 CLI。容器在临时工作区根据基线/现状/目标准备依赖更新与骨架迁移候选，不写现用源码。冲突或缺基线列人工项且不标直接可用；文本无冲突仍需语义与行为验证。支持明确路径的累计迁移，不支持或缺元数据则阻断说明路径；首版公共修复只最新稳定版本，无旧主版本回补承诺。

## Testing Decisions

- **已确认的主要测试边界**：用户已确认以容器启动后的完整系统为主要边界，通过正常浏览器登录、公开 API 和管理 CLI 验证行为；仅对会话并发、事务审计及升级冲突等难以仅靠浏览器稳定覆盖的情况补充必要集成测试。复用实际认证、授权、应用服务及持久化，减少仅供测试的内部接口。
- **好测试的标准**：从调用者可观察的结果、访问资格、状态变化、审计和产物判断正确性；不测试组件私有状态、函数调用次数或逐行复述实现。隔离测试环境使用自有样例和临时授权账号，不使用生产或来源项目业务数据。
- **当前仓库及参考边界**：Templux 当前只有说明与需求文档，尚无应用或现有测试入口可复用。来源项目已核对密码会话版本、登录限制、搜索、多选、分页、排序、图片和复制等行为，可作为验收案例参考；Catchouse prototype 不等于已验证生产路径。已查看 Skoope 排序循环测试所表达的升序/降序/取消案例，不据此声称全部来源测试已运行。
- **测试工具**：具体浏览器、测试运行器和 CI 版本由实施选择；测试执行环境在容器内，宿主不增加应用语言运行时。计时和并发场景可在测试环境控制时间或并发输入，但不得增加部署可用的认证绕过入口。

| 验收组 | 必须观察到的行为 |
| --- | --- |
| 独立启动及配置 | 空库初始化迁移成功再启动；已有配置值改动重启即可改变品牌、风格、导航及元素默认值；前后端可独立构建，组合不兼容有明确失败；无效配置不被默默采用。 |
| 首次授权 | 飞书组织不匹配拒绝；首次匹配登录 Pending 无业务访问；CLI明确授权后登录可访问；零角色、禁用与 Pending 无示例访问。真实飞书在有组织凭据环境单独验收，不要求常规自动化在线调用飞书。 |
| 账号及 Agent | 管理员与普通用户后端权限不同；Agent 默认无权限、授权后正常页面登录，PROD 默认拒绝；登录关联不能按相同邮箱自动合并；初始密码不出现在普通文本/JSON/诊断中，受限文件不静默覆盖。 |
| 管理不变量 | 同时降权或禁用最后管理员的并发请求不会把既有系统变成零有效管理员；首启零管理员仍可用 CLI 建立；未授权网页和 API 均不能管理账号审计。 |
| 会话 | 正常重启保留有效会话，已撤销不会恢复；当前退出只当前会话，全部退出撤销全部；密码重置、禁用、角色变化后新保护请求拒绝旧会话，包括旧飞书会话；范围失效扩展可触发同样结果。 |
| 闲置及心跳 | 人员/Agent 默认期限与独立配置有效；后台心跳不延长闲置；恢复可见/在线立即检查；明确失效退出无倒计时且不受未保存弹窗阻挡；网络故障与业务403不误退出。 |
| 登录限制 | 同IP同用户名窗口内5次触发固定15分钟限制，组合隔离、受限请求不延长、成功清理；时间边界、重启、多实例与并发下计数一致；过期可按规则重新尝试。 |
| 审计故障 | 注入审计写失败后账号/角色/关联变更未提交且报错；成功密码认证仅审计单独失败时仍登录且有运行错误；数据库整体故障不能登录放行；审计查询拒绝普通用户，留存清理不泄露凭据。 |
| CLI | 有终端无参数进入菜单；完整参数非交互执行；无终端缺参数及时非零退出；变更缺显式确认失败；JSON stdout 可直接解析且日志走 stderr；Web未启动可初始化。Ubuntu UAT/生产有真实主机入口验收要求（版本/架构待环境提供，尚未执行）；macOS 可选开发保留既有实测。Windows/WSL2 移出范围而非通过。 |
| 备份恢复 | 迁移前备份失败阻断，空库/无迁移正确跳过，外部参考如实记录；第6份成功后只清理超额自动备份，失败不顶替成功；缺恢复模式目标拒绝；原库停写确认、独立目标不自动切生产；实际恢复成功后旧会话全部拒绝。 |
| 搜索多选 | 指定字段整段包含语义、首尾空白及大小写符合规范；停止输入1秒内触发而不把网络耗时混入；每个选项行各点击区域仅切换一次，键盘和触屏可用；关闭提前应用、全选当前结果不改隐藏项。 |
| 分页排序及空结果 | 默认10及指定数量选项，下拉合法跳页、边界禁用；大小与排序变更回第一页；下拉表头同步、升降取消及基础次序；刷新恢复三项状态且调整不堆积历史；无结果保留表头与提示，错误/权限不足不假装空结果。 |
| 表单弹窗及内联行 | 失焦/提交/错误后重查与就近提示；默认表格无编辑入口，显式按行保存失败保留输入；真实未保存才提醒，保存中重复提交和主动关闭被阻止；超时标明未确认且不自动重试写入。 |
| 通知与维护 | 15秒进度及悬停/焦点剩余计时；桌面3窄屏1，排队显示才计时；同键同级合并计数不重置，溢出只丢等待项并有摘要；维护不计入队列、不可关闭、到点仍显示、刷新保留、明确结束移除且不自动停服；计划停服入口可显示维护页。 |
| 图片复制及面板 | 图片各关闭途径与焦点恢复、点图不关闭；备选源失败占位禁用、图库边界不循环切换重置；复制完整值成功约1.5秒本地反馈、失败不假成功；桌面面板边界及窄屏非模态行为，同一时间一个，替换遵从编辑保护。 |
| 响应式及示例 | 默认风格及代表性其它项目风格、横纵导航、图标模式、桌面/窄屏截图；表格只容器滚动、页面无横向溢出；示例访问按角色及环境，内存模拟可重置且移除不破坏认证和管理。截图供人工审查，不以像素差异作为首版自动门禁。 |
| 发布及升级 | 在隔离新项目上使用锁定包及清单，校验失败或组合不支持可明确发现；当前版本到支持目标生成累计补丁和报告；项目定制不被覆盖、基线缺失和文本冲突阻断可直接应用标记，语义检查失败报告；生成提案不自动修改现用源码、合并或部署。 |

- **交付检查**：提供每组关键场景的测试结果、代表性截图、容器入口说明及失败报告；有凭据飞书验收如未执行必须明确标记，不以密码登录测试代替飞书组织准入证明。备份须有实际恢复演练，升级须有独立新项目的提案演练。

## Out of Scope

- 来源项目采购、仓检、库存等业务流程及数据；模板内通用业务范围模型、范围编辑器和固定供应商/仓库/店铺字段。
- 公众自助注册、同部署多组织租户、后台自定义角色编辑器、人员自助改密、短信邮件找回、姓名或邮箱自动合并身份。
- Agent 认证后门、复用员工凭据、默认生产 Agent 登录、浏览器账号自动获得宿主权限。
- 宿主安装 npm、Node.js、Java 或数据库客户端；首版原生 PowerShell、其它数据库、ORM 或强制外部日志平台。
- 终端用户主题、导航方向、语言或个人时区切换；用户偏好跨设备同步；配置自动热更新。
- 强制每个新项目安装全部网页元素、完整样例业务、样例业务数据库和 API、默认生产开放示例。
- 默认表格编辑、隐式自动保存、自动重试结果不确定的写操作、多个独立浮窗层级管理、持久通知消息中心。
- 运行日志网页浏览器、首版审计导出、保证完整14天运行日志、浏览器后台精确计时、像素差异自动阻断。
- 全部新项目内容自动反向同步、模板持有全部项目写权限、自动升级合并或部署、首版强制远程 PR 集成、独立私有包仓库、目录脚手架生成器、旧主版本修复回补承诺。
- 内置定时异地备份服务、数据库备份自动包含 .env和文件资产、假定外部数据库建库权限、恢复自动切换生产连接、模板调用云快照平台 API。
- 本规格发布不包括应用实现、来源项目修改、Git 提交或推送、部署上线及实际包发布。

## Further Notes

- 本规格依据已完成的126项访谈记录、现行专题规范与29份 ADR 合成；按用户最新明确决策和后续澄清解释历史记录。已确认默认值具有约束力，来源代码现状不自动成为规范。
- 来源核对采用先三项目共通答案、明显分歧交 TypeSafe、实质选项概率严格大于75%可自动采用、其余由用户选择的流程。TypeSafe 只用于本次决策辅助，不因此成为运行模板的依赖；既有外发授权不等于允许发布实际密钥、源码或业务数据。
- **实施设计必须补齐但不重开全面访谈**：共享包公开接口及禁止覆盖边界；发布产物存放与获取授权；维护入口停写和恢复机制。这些影响发布与安全，必须在相关能力交付前记录具体方案及验证结果，不能因为标签为 ready-for-agent 就宣称已决定。
- **其余实施细节**：人员重置密码的安全交付、登录关联验证与冲突、会话失效原因枚举、可信代理和限流清理、审计脱敏及其它事件失败策略、迁移锁和恢复校验、配置格式和合同、CLI 参数/退出码/文件权限、视觉变量及断点、通知容量和同键内容变化、搜索中文输入与清空/回车/请求竞态、浮层焦点、测试工具及 CI 由实施设计具体化。沿用来源证据和可配置默认，不把未选方案伪装成用户确认；只有改变范围、安全或升级兼容性的实质分歧再定向澄清。
- **实施推进建议**：先确定公开合同与系统启动闭环，再交付认证授权及容器管理，再交付网页元素与示例，最后贯通备份恢复和真实升级提案演练。可以分解任务，但不得把首版明确范围悄悄移出交付。
