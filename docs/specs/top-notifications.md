# 顶部普通通知

T16/#17、父规格故事83–84，沿用web-elements历史及ADR0012/0013/0020。正式通用控制器shared/notifications与components/elements/notifications不依赖examples。维护通知另票，不加入普通队列；无消息中心、业务API、持久化或外发。

## 调用与生命周期

每个页面/已验证账号作用域拥有一个createNotifications实例及一个Notifications视图；不得在服务端进程全局跨请求共享。push须显式title/message，可选level（info/success/warning/error，默认info）、key和durationMs。文字按纯文本渲染，title非空≤200字符，message非空≤4000、key非空≤200；不传HTML/密钥/密码或私有交付。项目在真实提交完成后自行决定通知内容，不把通知当授权或操作成功证据。

默认15秒，单调performance.now计时；控制器可注入now供确定性测试，视图100ms协调进度。时间只扣当前可见、未暂停项。等待项显示时才开始；后台节流或设备休眠后按当前单调时间协调，不承诺后台精确到期/播报，未显示项不追溯消耗时间。

四级仅改变可见标签/语义与样式，不改变FIFO、自动消失或优先级。全部普通提示用独立polite/atomic live region，计时进度不进入播报文本；通知出现不夺焦点，不承诺所有读屏产品播报顺序。错误亦为普通可关闭15秒提示，不取代就近字段/表单错误。

鼠标hover和焦点为两个独立暂停原因，必须均离开才按剩余继续；焦点内部移动不恢复。触屏pointer不新增hover/正文点击暂停，键盘随后进入仍暂停。混合设备实际已有鼠标悬停不因触控事件被取消。正文过长可滚动且键盘可达，无专用暂停按钮。关闭被聚焦项/断点移走该项时，焦点移到下一可见关闭入口；没有项时用消费者returnFocus，仍存在才可返回，不自动聚焦普通到期项。原生弹窗top layer优先于通知。

每次操作先协调当前到期项，再处理本次命令。精确同刻到期的项先全部移除，再FIFO提升等待项；close已结束ID为false。clear清所有活动内容和省略数，不留结束历史；end清空且永久拒绝该实例后续push（null）。视图监听session-ending同步end、不保留旧账号内容；页面卸载时所有者应clear，视图只解除计时/订阅。刷新/导航不恢复通知，不跨账号复用实例。

## 合并、容量与断点

- 只有显式相同key且同level的活动项合并，包括可见/暂停隐藏/等待；无key即使文字一样也独立。关闭/过期/溢出移除项不参与。
- 同键内容或时长变化仍只count+1，**保留首次title/message/duration**、原位置/剩余/暂停；需要新内容的调用者换键或关闭后重新发布。count及省略数在MAX_SAFE_INTEGER饱和，不延长倒计时。
- 默认可见桌面3、≤700px窄屏1。收缩把尾部已显示项移到单独暂停区，剩余冻结并清除不再存在DOM的hover/focus原因；扩展或空槽优先恢复这些项，再取从未显示的等待项。焦点仍在可见项时保持暂停；恢复项不恢复幽灵焦点/hover。暂停区最多maxVisible-1（最多9）项，不能借收缩无界积压。
- 等待容量默认50（可配1–500），满时只移除最早从未显示等待项，保留最新并累计省略数；不淘汰可见或此前显示的暂停区。单独省略摘要不占队列/可见上限，不含丢弃正文，一直累计到clear/end或页面卸载。并非可复取记录。

## 呈现配置

`elements.notifications`默认`{durationMs:15000,desktopVisible:3,narrowVisible:1,queueCapacity:50}`。durationMs整数1–3600000，可见数各1–10（两者独立），queueCapacity1–500。单次push可选合法durationMs覆盖，合并仍取首次。省略整个分支补默认；旧三字段分支只缺新增queueCapacity补50；显式null/空串/空对象/不完整旧字段/未知键/非法范围拒绝。运行载入为不可变快照，修改文件重启生效，不热更新、不修改现用presentation。

采用视图须传经过校验的桌面/窄屏可见值。构造控制器visible与首屏项目配置一致；视图挂载用matchMedia校准并监听变化。默认CSS使用项目主题变量，顶部边距1rem，桌面宽≤34rem、窄屏视口内；长正文自身滚动，通知容器在极短屏还可整体滚动。未实现维护/跨层管理或可恢复草稿。

## 受保护示例

/examples的通知面板仅页面内存；正常认证/授权门保持。可选标题/文字/严重程度/显式键，空白键示例按无键；连续60条展示有界队列与摘要，长文验证滚动。清除和整页重置都清内存，不向任何外部组织发通知，不自动把其它示例结果改为全局通知。
