# 图片预览、图库与失败备选

T17/#18、父规格故事87–89；沿用web-elements及ADR0012/0013/0020。通用控制器shared/image-preview、React ImagePreview/native loader与合成examples分离，无业务API/SQL、照片后端或外发。

## 采用与源策略

ImagePreview必须传`image:{id,alt,sources}`。ID唯一稳定、非空≤200字符，alt必须有意义且非空≤2000；不能用文件名猜业务解释。sources是当前同一图片的候选列表（最多20），先拒绝控制字符/反斜杠，再trim其余候选、去空及规范化后的重复，保持次序。没有有效候选时占位且打开入口禁用。列表只接受本地根路径（不是//、无反斜杠或控制字符）与无用户名/密码的HTTPS绝对地址，不接受相对路径、HTTP、data/blob/javascript。本地候选在dot段规范化后再次校验序列化结果，不接受变成协议相对的双斜杠前缀，并按页面地址重新解析确认仍是本origin；HTTPS序列化结果保持绝对地址且无凭据。远程来源须由项目按隐私、许可及组织域约束选择；HTTPS语法通过不代表可信/获授权。本组件不作服务端请求，不是图片代理/SSRF保护；默认no-referrer、纯alt文本，不输出URL诊断。

原生Image请求并完成decode后才ready；complete单独不能代表成功。每图按候选顺序加载/解码，失败只转该图下一源；全部失败为终态占位，禁用该图打开，不自动重试/跳图库下一张。ready资源仅实例内缓存，关闭再开不重试；实际显示img若随后失败也推进该图备选。没有持久图片缓存管理或自动网络重试按钮。

每次尝试有token；失败换源、取消、切图及代次使旧结果无效。初始图片加载归持续显示的缩略图所有：切图或关闭弹窗不取消其同一次备选等待，完成后仅恢复入口，不自动重开。非初始图库项在切走/关闭时中止本地loader等待并保留候选位置，明确再访问可恢复尚未完成的候选，不回头重试失败候选；卸载清理handler/abort及active标记，即使传输忽略abort也不接收晚结果。浏览器或远端仍可能完成网络请求，不声称取消服务端。

描述/列表/选中ID或设置内容变化会替换整个实例并关闭旧弹窗，取消旧等待，重新加载新描述；原打开控件已随实例销毁时不强行聚焦新控件。纯对象重建但规范化内容相同不重置。loader适配器每实例冻结，项目应提供稳定函数并在账号/授权作用域变化时卸载旧实例，不能跨账号复用缓存。

## 显式图库及身份

可选`gallery:{enabled:true,images}`须提供1–100个项目描述，唯一ID，初始image须在列表且内容一致。未提供或enabled:false只采用单图；单图不显示图库工具。列表多张才显示上/下一张与当前位置，边界禁用且不循环；切换重置缩放平移，加载中/失败保持当前索引，不伪装为下一张成功。独立源不共享失败计数。

默认native image loader无法读取HTTP状态，403/网络/解码失败都只作图片资源失败，不据此退出身份；身份仍由正常SessionGuard/API保护。真实受保护图片项目可传`load(source,signal)`适配器，用既有sessionFetch处理实际401原因/强制重登，返回ready（须同源已验证解码尺寸）、failed或ended；403/网络不得冒充401。适配器不授予后端访问，不能仅返回假尺寸跳过权限。session-ending同步end/关闭全部图片DOM、取消加载且拒绝旧结果；不被dirty/等待守卫阻挡。不将公开合成SVG的访问策略用于业务照片。

## 关闭、焦点和手势

原生dialog.showModal使背景不可操作，打开聚焦关闭按钮、Tab/Shift+Tab圈定。关闭按钮、Escape或外侧遮罩关闭；点图不关闭。遮罩关闭要求同指针down/up均在弹窗框外且位移≤5px，再由对应click完成关闭；遮罩down取消默认兼容鼠标行为，click先取消默认并停止传播，避免焦点被后续mousedown抢走或点穿底层。拖动从图片开始或结束不作遮罩点击。关闭恢复仍存在、未disabled/隐藏/inert的打开按钮；控件被删除则不猜其它焦点。会话结束不恢复失效页面焦点。

默认等比contain且不把小图放大，fit为相对比例1。可选zoomPan后显示缩小/放大/适配，默认上限4、项目1–8整数；0恢复、+/-每次0.5，方向键每次40 CSS像素。锚点固定视口中心，缩放按新旧比例调整现有平移再clamp；不是光标点缩放。鼠标主键或单触点拖动，仅放大后捕获pointer并禁止浏览器默认触摸动作；小于溢出轴不允许平移，任一轴最多移动放大图超出视口一半，避免暴露空白边。第二触点或非primary触点加入即取消既有拖动并释放捕获，原触点即使剩一个也不能继续；全部触点结束后新的单指才可拖动。pointercancel/lostpointercapture取消当前拖动，抬起在视口外也清理；切图/关闭/缩放重置及销毁释放捕获。无滚轮接管/双击/捏合、旋转或裁剪；两种设备都可用同样的按钮与拖动。

切图、加载成功/失败和视口尺寸变化恢复fit/平移0，避免旧尺寸越界；ResizeObserver按内容框协调。长alt完整保留、可滚动，窄屏工具换行、图片区域裁剪放大部分、整个短屏弹窗可滚动。原生焦点/触摸与软键盘跨平台仍需项目验证。

## 配置与示例移除

`elements.images`默认`{zoomPan:false,maxScale:4}`；整个分支缺省兼容旧schema1，显式null/空串/空对象/缺字段/未知键/错误类型或maxScale越界拒绝。公共设置可按项目显式覆盖；图库始终依赖项目显式列表，不由全局配置猜测。现有呈现载入快照、改值重启生效，不热更新。

受保护/examples提供单图/显式图库/可选缩放、缺失→损坏→有效源、全部失败和空来源。assets位于public/examples，仅代码生成SVG与刻意损坏的纯文本，不含来源业务照片。删除examples模块/copy时可一并删除这些合成资产，正式认证/管理/审计及共享图片组件不反向依赖它们。
