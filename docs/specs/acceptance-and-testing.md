# 验收与测试规范

## 已确认

- 交付关键逻辑测试、API 集成测试、真实浏览器关键流程及控件交互验收，支持容器运行。
- 浏览器通过正常密码登录页面及明确授权的独立测试账号认证，复用真实权限与会话流程，不增加认证后门。
- 自动化在隔离测试环境执行，不使用生产或来源项目业务数据；临时账号的创建与授权须由受控测试流程完成，不改变首登 Pending 规则。
- 飞书真实组织登录另在有凭据环境验收，不要求无凭据的常规自动测试调用真实飞书。
- 验收应检查确认的行为与权限边界，不仅重复实现细节。
- 自动检查交互与关键布局约束，生成代表性主题、视口截图供审查；首版不维护以像素差异自动阻断的截图基线。

## 待确认或细化

- 测试工具、容器测试入口、CI 接入及产物。
- 平台、视口及可配置变体覆盖矩阵。
- 测试账号回收、失败报告与飞书验收操作。
