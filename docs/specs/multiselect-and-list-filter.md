# T12 多选与列表筛选合同

依据 #13/#1、ADR0012/0013及T11搜索合同。共享组件在components/elements；纯选项操作在shared/multiselect，单向供examples使用。纯浏览器合成示例，不新增业务API、表或认证入口。

## 基础控件

MultiSelect需要label、options（唯一非空string value及可识别label）、values（显式选项的无重复子集）、onChange，onClose可选。受控选中值由采用者保存；没有默认业务字段、授权、自动持久化或提交。选项集在一次挂载期间固定，变更选项集需明确迁移选中值或重新挂载；未知或重复选中值拒绝。表单、显示字段等采用基础控件并自行决定提交，列表计时不强加这些用途。

原生label包裹checkbox、文字及整行空白，唯一onChange读checked；不另注册行toggle。鼠标、触屏点击及checkbox Space均只触发一次。搜索只匹配选项label，整段trim/lower包含，不拆词、不搜索value。全选当前结果为当前匹配集合的checkbox，部分选中显示原生indeterminate；选或取消只更新匹配项，隐藏值保持。无匹配提示且全选禁用。返回值按声明选项顺序，稳定value不以显示名称作身份。

按钮有字段名/已选摘要、expanded/controls，非模态dialog有名称、搜索label及可识别选项。采用浏览器auto popover顶层，点击外部/Escape关闭；按钮/关闭按钮可关闭，焦点离开控件关闭。打开聚焦选项搜索，Escape及关闭按钮恢复触发焦点；外部点击保留外部目标焦点。Tab可访问搜索、全选、各项和关闭，不作模态焦点陷阱。关闭清空选项搜索。

浮层依据触发位置和visualViewport，在下/上方可用空间内选择较大方向，宽不超过352px或视口减24px；长文本换行、内容内部滚动，resize/滚动/视口变化重新定位。不裁选项名，不让页面横溢出。原生Popover要求当前支持该API的浏览器；本票实际验证Ego Chromium，不声称旧浏览器polyfill或所有屏幕键盘矩阵。

## 列表适配

ListMultiSelect显式提供同一options/label、settings、onIntent/onApply，初始全选。草稿即时显示，任何变更立即onIntent，使旧读取版本失效；每次勾选重新计时，停止后调用onApply最终值。提前关闭取消定时器并立即应用未提交草稿，不等待、不显示确认按钮；没有脏变更时关闭不重复提交，卸载取消等待且不悄悄提交。

elements.multiselect为可省schema1分支，缺省delayMs1000；完整覆盖整数1–1000。显式null/空对象/部分/错误类型/未知字段/越界拒绝。原项目文件缺分支由共享loader补，不改磁盘原文件；项目修改已支持值后重启生效，进程使用启动快照。新增分支需先部署支持代码，旧镜像不保证识别。

SearchList可选renderFilters({onIntent,onApply})接入一个聚合筛选器。筛选器的新草稿立即onIntent，提交时先更新采用者的筛选条件/稳定load回调，再onApply；onApply不接选项值、不猜业务字段。多个筛选器需由采用者聚合草稿和提交边界，不能各自将另一个尚待提交的条件标记完成。本票示例一个分类筛选；匹配读取由示例load显式实现。

搜索与筛选有各自pending状态；任一待应用时不发布旧读取。搜索Enter/清空只提交搜索，不偷偷提前提交筛选；关闭筛选只提交筛选，不提交未结束IME/搜索草稿。均提交后以最新搜索term及最新筛选读取，版本取消和generation保护照旧。结果成功后仍执行显式fields/matches；全选表示字段无额外限制（包括未来未列出的值），空选明确无结果，子集由采用者明确映射字段值，不把空数组当全部。

错误/业务403无资格/loading/waiting/成功空保持独立，表头/搜索/筛选保留。网络错误不退出；明确401沿SessionGuard/session-client即时强制登录，不等控件计时。真实项目load必须提供后台授权范围、筛选映射与错误解码；内存过滤不是权限检查，不把部分分页误当完整读取范围。本票不实现分页排序或业务范围。

## 示例

/examples沿T10正式认证与SQL，名称/编号统一搜索与分类多选组合。分类包含展示、测试及独立扩展长文本选项，无真实数据；扩展无记录的单选可演示成功空，全部选仍不限制已有行。慢/竞态/读取错误/无资格情景为合成内存源；重置按钮或刷新重新挂载，恢复全选、空搜索及默认配置，不影响真实账号、审计或配置。独立示例移除合同沿T10，公共模块不反向import示例。

## T12 F1 等待状态补充

搜索计时先提交而筛选仍pending时继续waiting/busy=false，不提前标记读取。搜索提交只推进条件并作废旧源，loading由协调器真正run时发布；二者均提交后才调用load。旧成功/错误即使忽略取消仍拒绝。实际组件调用计数与生产模式UI证据见 [F1修复验收](../discovery/t12-f1-acceptance.md)，初审历史保留。
