# 控件示例规范

## 已确认

- 模板独立启动提供登录、账号管理及控件示例，使用自带样例数据，不增加完整样例业务流程。
- 控件按需采用，不要求新项目固定包含全部控件或示例页面。
- 新生成项目保留独立可移除的示例目录及页面，开发测试默认启用、生产默认关闭；新项目可通过项目配置启用并按明确访问规则开放。
- 示例演示已确认的统一样式、行为、必填配置及可选变体，不固化来源项目业务或连接真实来源数据。
- 控件示例数据放独立文件，操作在浏览器内存模拟，刷新或重置恢复；不新增示例数据库表或业务 API。真实登录、账号管理及审计仍使用正常后端。
- 示例启用时，已批准、有角色的正常账号可访问，包括管理员、普通用户与获授权 Agent；匿名、Pending、禁用及零角色账号不可访问。示例权限不授予真实管理权限，新项目可调整规则。

## 待确认或细化

- 样例文件组织、模拟加载及失败状态的展示。
- 示例入口和关闭时的路由行为。
- 示例覆盖清单、代码使用说明及重置方式。

本文件是需求规范，不表示示例已实现。
