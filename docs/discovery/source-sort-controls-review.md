# 三项目排序控件核对

仅提取控件交互，不复制业务排序字段、比较算法或取数方式，不要求每个列表或每列都可排序。相关函数由图定位，`cycleTableSort` 入向追踪至 `OverviewTable`，精确 snippet 与直接源码核对结合。四个证据文件覆盖均 metadata_match、无已记录问题，属 best-effort；未做浏览器验收。

| 来源 | 证据 | 行为 |
| --- | --- | --- |
| Supplieroom 采购单 | `src/modules/supplier-po/ui/supplier-po-workspace.tsx:96–104,282–295` | 卡片列表独立排序下拉，含默认及业务字段升降序；修改排序回第一页。不提供可比表头点击循环证据。 |
| Skoope 总览 | `src/components/overview-table.tsx:88–102,134,144–145,155–165`；`src/modules/identity/overview-table.ts:39–42,69–85` | 排序下拉与可排序表头并存，共用 sort 状态；表头新列先升序、再降序、再取消，修改回第一页；箭头与 aria-sort 显示状态。取消使用其稳定基础次序，模板不复制其业务比较器。 |
| Catchouse 看板 prototype | `prototype/catchouse-app.js:1029,1033,2001` | 所查桌面可排序表头新列先降序，同列升降交替，不含点击取消；修改回第一页，箭头显示方向。未证明生产接入，不能概括全项目排序入口。 |

共同点：排序改变回第一页；一次一个字段，界面标示当前选择/方向。字段及基础次序由新项目提供，不强制前端内存排序。
