## 自动选择规则

- 用户授权使用 TypeSafe，候选选项实际概率严格大于 75% 时自动选择。
- 比较 Choice 返回的 `probabilities[choice]`，不将 `confidence` 当成选项概率。
- 信息不足这一结果表示需要继续提问，不作为架构方案。
- 请求与原始返回保存在本目录；每个结果均记录是否触发自动选择。
- 首次 API 请求被自动审批拒绝后，用户明确回复“批准”，允许发送该次模板需求摘要与规划信息至 TypeSafe 官方 API。
- 用户随后明确批准将第二次升级策略问题，以及后续访谈中的需求摘要、已确认决策和候选选项发送至 TypeSafe 官方 API；此持续授权不包括源码、业务数据或凭据内容。
- 该授权用于访谈决策，不代表模板产品必须集成 TypeSafe。

文档依据：[TypeSafe Choice](https://docs.typesafe.ai/primitives/choice)、[HTTP API](https://docs.typesafe.ai/api)。
