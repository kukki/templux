# 容器内执行 CLI，提供人工与自动化入口

用户确认 Linux、macOS 的 Shell 入口及 Windows 经 WSL2 使用的方式。宿主不要求额外安装 npm、Node.js、Java 或数据库客户端，应用运行环境和命令逻辑均在 Docker 服务容器或一次性管理容器内。人工使用无参数交互菜单，无需记忆参数；Agent 可使用完整参数的一行脚本调用，两种入口共用命令及校验逻辑。基础 Docker、Compose 与 Shell 是宿主前提，不提供首版原生 PowerShell 包装；非交互退出码、输出与错误处理规范待细化。

宿主入口只作容器调用、参数及退出码转交，菜单、应用参数解析、校验和实际操作均在容器内。现行规范见 [管理 CLI](../specs/management-cli.md)。

用户进一步确认：无参数且有交互终端时进入菜单；完整参数直接执行，提供显式非交互模式。非交互或无终端时缺少必填参数立即报错并返回非零退出码，不等待输入；人工可显式选择交互补齐。
