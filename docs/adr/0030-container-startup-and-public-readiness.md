# 管理容器编排启动并以公开状态验证数据库结构

T01 采用容器内 Docker CLI 与 Compose 编排启动。宿主入口只转交项目目录、参数及退出码；管理容器挂载宿主 Docker socket，以宿主运维权限构建和管理当前项目。前后端不挂载 socket，使用非 root 用户。

启动先构建、启动数据库，再运行一次性迁移容器；迁移在同一数据库连接上持有非阻塞 advisory lock，按版本和校验和核对历史，每项迁移和历史记录同事务提交。失败中止后续启动，Web 不迁移；该决定不替代后续已有库升级前备份任务。

公开状态接口只报告应用与数据库结构就绪，不提供数据库凭据或管理能力。结构未迁移、历史校验不一致或数据库不可达时返回503；页面按真实响应显示不可用。当前初始迁移只建立应用 schema，不建立业务或示例数据表。

迁移后、显式检查与状态接口共用结构校验，除了历史版本及校验和，还核对当前必需的应用 schema 确实存在。后续表结构由对应切片扩充校验合同，迁移记录存在不代表结构仍存在。PostgreSQL 锁定本次实际测试的18.6及镜像摘要。

本机默认端口31000及31800，绑定回环，避免干扰现有应用。内置开发凭据不构成生产配置承诺。开发测试通过完整HTTP和CLI边界验证，真实浏览器审查桌面与窄屏页面。
